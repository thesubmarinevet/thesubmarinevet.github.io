# thesubmarinevet.com

Website for **The Submarine Vet** (parent brand), **Silent Service Trading** (software platform) and **Command Center** (flagship NinjaTrader 8 app).

Static site on GitHub Pages: `main` is live at thesubmarinevet.com (`CNAME`). No build step is needed to deploy — every page is plain HTML.

## Pages
| URL | File |
|---|---|
| `/` | `index.html` |
| `/command-center/` | `command-center/index.html` |
| `/pricing/` | `pricing/index.html` |
| `/about/` | `about/index.html` |
| `/support/` | `support/index.html` |
| `/command-center/thanks/` | `command-center/thanks/index.html` — **Stripe redirects buyers here; don't move it** |
| any missing URL | `404.html` |
| `/lexicon/` | redirect to `/` |

Shared: `assets/site.css` (design), `assets/site.js` (menu, year, old-anchor redirects, checkout links), `assets/img/` (favicon, screenshots).

## Editing
- Pages are generated by `tools/build_site.py` so the header, footer and metadata stay identical. Edit the script, then run `python3 tools/build_site.py .` from the repo root and commit the HTML. Small text fixes can also be made directly in the HTML.
- **Screenshots:** each placeholder frame has an HTML comment naming the file to add (e.g. `/assets/img/cc-workspace.png`). Use Sim accounts only — no real account names, numbers or balances.
- **Feature status** on the Command Center page: `a` = Available, `t` = In testing, `p` = Planned (in `build_site.py`). Keep it matching the build customers get.

## Checkout (Stripe)
- The three Stripe payment links are set in **one place**: `BUY` at the top of `assets/site.js`. Buttons carry `data-plan="monthly|annual|lifetime"`; without JavaScript they fall back to email.
- Changing a link changes where customers are charged — get approval first. Test any payment change in Stripe test mode.
- Stripe sends buyers to `/command-center/thanks/` after payment. The Lifetime sold-out message points to `/command-center`.

## Deploy
Work on a branch, review, then merge to `main`. GitHub Pages republishes within a few minutes.
